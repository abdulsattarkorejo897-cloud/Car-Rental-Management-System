# 🚗 Car Rental Management System

## Project Overview
The Car Rental Management System is a Java-based console application developed as a 2nd Semester BS Information Technology project.

The system allows customers to register, view available cars, check car availability, select a vehicle, calculate rental charges, and generate a booking receipt.

## Features
- Customer Registration
- Customer Information Management
- Display Available Cars
- Car Availability Checking
- Already Booked Car Warning
- Rental Price Calculation
- Booking Confirmation
- Automatic Booking Receipt

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE
- Java Development Kit (JDK)

## Concepts Demonstrated

## How to Run
1. Download or clone this repository.
2. Open Eclipse IDE.
3. Create or import a Java project.
4. Add `CarRentalSystem.java` to the source folder.
5. Run the `CarRentalSystem` class.
6. Enter customer details and follow the instructions.

## Project Limitations
- Console-based application.
- Booking information is not permanently stored.
- No database connectivity.
- No real payment integration.
